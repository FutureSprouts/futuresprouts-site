Grow Widget Demo

Standalone demo. This page is opened straight from the filesystem without the FutureSprouts site scripts, so window.FS_CART is not present. That means the "Add to Request List" buttons render in a disabled state on purpose, and the widget logs a console note explaining why. On the live site, where script.js defines FS_CART, the same buttons add the matching seed pack to the visitor's Request List. Include order on a real page: grow-widget.css, then grow-data.js, then grow-widget.js, then call initGrowWidget with a mount element or its id.

Accessibility

Everyone should be able to request seeds.

Our programs go to classrooms and community groups, so this site has to work for teachers, parents, and students using screen readers, keyboards, magnification, and older phones. This page says plainly where we stand and how to tell us when we have got it wrong.

Conformance status

We aim to meet WCAG 2.1 Level AA. We are partially conformant, which means most of the site meets that standard and some parts do not yet. We do not claim full conformance, because we have not had an independent audit.

What we have done

  • Every page has a main landmark, a skip-to-content link, and one page heading.
  • All interactive controls are reachable and operable by keyboard, with a visible focus ring.
  • Text and interface colours are checked against WCAG contrast thresholds in both the light and dark themes.
  • Animation is disabled for visitors whose device asks for reduced motion.
  • Layouts are tested down to a 320 pixel wide screen without sideways scrolling.
  • Form fields have programmatic labels, and status messages are announced to screen readers.
  • Pages are tested with the axe accessibility engine in both themes.

Known limitations

We would rather list these than pretend they are not there.

  • Some forms use placeholder text where a visible label would be clearer. We are moving to visible labels.
  • Our donation checkout is handled by PayPal, and we do not control its accessibility.
  • Testing so far has been automated plus manual keyboard checks, not testing with assistive technology users.
  • Some decorative illustrations carry no text alternative by design, since describing them would add noise.

Tell us about a barrier

If any part of this site blocks you, email info@futuresprouts.org with the page address and what happened. We aim to reply within five business days. If a barrier stops you from requesting supplies, say so in the message and we will take the request by email instead so you are not left waiting on a fix.

Assessment date: this statement reflects the site as most recently reviewed. It is updated when we change the site or learn about a barrier.
